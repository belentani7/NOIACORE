# LIOS V4: Local Intelligence Operating System — "Legacy Edition"

Esta versión no es solo una actualización; es el nacimiento de **LIOS (Local Intelligence Operating System)**, el primer sistema diseñado para que tu inteligencia y tus patrones de decisión trasciendan generaciones.

## La Visión: Relevancia de la Década

LIOS V4 transforma tu PC en un **Santuario de Conocimiento**. Ya no solo organizas archivos; estás construyendo un **Patrimonio Digital** que puede ser legado, preservado y evolucionado.

### 1. Grafo de Conocimiento Semántico (`KnowledgeCurator`)
- **Memoria Eterna:** Cada archivo, nota y decisión se conecta en un grafo semántico versionado.
- **Inmutabilidad:** Las versiones del grafo están firmadas criptográficamente, asegurando que tu conocimiento sea íntegro para el futuro.
- **Portabilidad:** Exporta tu cerebro digital en formatos abiertos (JSON-LD) que sobrevivirán a cualquier plataforma actual.

### 2. Huella de Identidad Digital (`PatternArchivist`)
- **ADN Cognitivo:** El sistema destila tus patrones de decisión en una huella de identidad.
- **Anonimización:** Puedes legar tu "forma de decidir" de manera anónima para que tus sucesores hereden tu intuición sin comprometer tu privacidad total.

### 3. Broker de Legado y Testamento Digital (`LegacyBroker`)
- **Transmisión Controlada:** Define quién accede a qué y bajo qué condiciones (ej. "Solo mi hijo puede ver mi grafo de investigación después de 2050").
- **Cifrado de Grado Militar:** Tu testamento digital está protegido por algoritmos de derivación de clave robustos (PBKDF2 + Fernet).

## Arquitectura de Legado

| Módulo | Función Vital |

## Cómo Iniciar tu Legado

1.  **Instala las dependencias de seguridad:**
    ```bash
    pip install cryptography
    ```
2.  **Ejecuta el Sistema:**
    ```bash
    python main_agente_v4.py
    ```
3.  **Configura tu Testamento:** Usa la interfaz para designar herederos y activos. El agente te guiará discretamente en la creación de tu primer legado.
