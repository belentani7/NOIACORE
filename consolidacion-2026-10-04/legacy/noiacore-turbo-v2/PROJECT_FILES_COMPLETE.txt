=== CÓMO USAR ESTE CÓDIGO ===

1. DESCARGAR
   git clone <repo>
   cd of1p-production

2. CONFIGURAR ENV
   cp .env.example .env
   Editar .env con OpenAI, Stripe, WhatsApp keys

3. DOCKER LOCAL
   docker compose up --build
   Frontend: http://localhost:3000
   Backend: http://localhost:8000
   Docs: http://localhost:8000/docs

4. SEED DB
   docker compose exec backend python seed_db.py
   Carga 20 servicios + 10 proveedores demo

5. TESTS
   curl http://localhost:8000/health
   curl http://localhost:8000/api/services

6. PRODUCCIÓN
   Ver DEPLOYMENT.md
   Frontend → Vercel
   Backend → Railway
   DB → Supabase
