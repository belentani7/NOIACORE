# NOIACORE LAB / SINGLE PAGE SPECIFICATION & MONOCHROME-PURPLE SYSTEM

## 1. Directrices de Diseño y Restricciones
- **Estructura**: Una única página fluida (*single page*) con anclajes de navegación precisos y modales de profundidad, eliminando cualquier salto de página artificial.
- **Paleta Cromática**: Negro absoluto (`#000000`) como fondo y sustrato único, grises minerales fríos (`#111113`, `#1A1A1E`, `#8A8A93`) para estructuras y bordes, blanco puro (`#FFFFFF`) para tipografía primaria y **púrpura profundo / violeta eléctrico (`#7C3AED`, `#A855F7`, `#4C1D95`)** como el **único acento cálido y místico** permitido.
- **Prohibiciones cromáticas estrictas**: Cero azul saturado, cero tonos cálidos anaranjados o rojos, cero degradados coloridos.
- **Tipografía (Máximo dos familias)**: 
  1. *Space Grotesk* para títulos y elementos de interfaz de alto impacto (geométrica, limpia).
  2. *JetBrains Mono* para datos, telemetría, metadatos y subtítulos técnicos.

## 2. Arquitectura de una Sola Página
La experiencia se organiza en secciones continuas sobre el fondo negro absoluto:
1. **Hero / El Umbral**: Isotipo minimalista de la A mayúscula, haz de luz cenital vertical, nubes volumétricas y subtítulo aforístico.
2. **El Manifiesto / Fundamento**: Definición filosófica y ontológica extraída de los documentos de análisis, con tipografía monovolumen y respiración asimétrica.
3. **El Ecosistema (Módulos 01–10)**: Tarjetas de arquitectura de sistema en grises oscuros con sutil borde púrpura al hover.
4. **Telemetría y Estado de Campo**: Indicadores en tiempo real con barras de estado purpúreas y flujo de señales.
5. **Consola Interactiva**: Terminal cognitiva modal integrada para comandos de diagnóstico.
6. **Cierre / Contacto**: Canal de transmisión y especificación temporal.
